100% Fully Dynamic Architecture

InterioCRAFT Website Builder Theme

Complete Technical Architecture, Database Flow, Controller Mapping, and Isolated Styling Guide

1. Is this Website Builder Theme Static or Dynamic?

The website builder is 100% FULLY DYNAMIC. None of the text, numbers, images, services, portfolio projects, or testimonials are hardcoded.

How It Works: All data is retrieved live from the Database (wb_agency_settings table) via Eloquent Model WbAgencySetting.php. When a user updates any content in their User Dashboard, the change is written directly to the database and immediately reflected on the live frontend site in real-time.

2. Step-by-Step Data Flow: Database to Browser Screen

1

User Saves in Dashboard

The user edits content (e.g., hero title, 4 stat cards, logos) in their User Dashboard form. Form POST submits to AgencyAdminController.php.

2

Database Persistence

WbAgencySetting.php stores fields into wb_agency_settings table. Stats, services, team & portfolio arrays are stored as JSON strings (cased to array).

3

Route Execution

A visitor accesses /templates/interior or custom subdomain (site.youverse.in). routes/website-builder.php dispatches request to FrontendController.php.

4

Controller Data Fetch

FrontendController::interiorTemplate() executes WbAgencySetting::getInteriorDefaults(), fetching DB records or falling back gracefully if unconfigured.

5

Blade View Rendering

The data object $interior is passed into index.blade.php. Blade loops over $interior->stats_data and renders running counters & components.

6

Isolated CSS & JS

The master layout layout.blade.php links public/css/website_builder/interior_theme.css, providing isolated, encapsulated visual styling.

3. Real Code File Mapping & Code Snapshots

Here is the exact code snippet driving the dynamic data flow in this theme:

A. Model Defaults & Fallbacks (app/Models/WebsiteBuilder/WbAgencySetting.php)

public static function getInteriorDefaults($customerId = null)
{
    $setting = self::where('customer_id', $customerId)->first();
    if (!$setting) {
        $setting = new self();
        $setting->site_title = 'InterioCRAFT';
        $setting->hero_badge = 'Our Home';
        $setting->stats_data = [
            ['number' => '8+',   'label' => 'Years of Experience', 'icon' => 'fa-trophy'],
            ['number' => '250+', 'label' => 'Projects Completed',  'icon' => 'fa-house'],
            ['number' => '98%',  'label' => 'Client Satisfaction', 'icon' => 'fa-star'],
            ['number' => '24/7', 'label' => 'Design Support',      'icon' => 'fa-headset'],
        ];
    }
    return $setting;
}

B. Frontend Controller Rendering (app/Http/Controllers/WebsiteBuilder/FrontendController.php)

public function interiorTemplate()
{
    $interior = \App\Models\WebsiteBuilder\WbAgencySetting::getInteriorDefaults();
    return view('website_builder.interior_template.index', compact('interior'));
}

5. How Theme Isolation Works

The interior_template is designed to be completely isolated from other website builder themes (such as agency_template):

  • Namespace CSS Prefixes: All CSS classes in interior_theme.css are prefixed with .ic- (e.g., .ic-hero, .ic-btn, .ic-container, .ic-stat-box), preventing style collision with main application or other templates.
  • Isolated View Directory: All Blade views reside under resources/views/website_builder/interior_template/.
  • Independent Settings Model: Uses template_type = 'interior' within WbAgencySetting, allowing users to customize their interior agency site without corrupting digital agency settings.
